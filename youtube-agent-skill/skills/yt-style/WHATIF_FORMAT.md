# WHAT IF format (18:00 / -PM runs)

Owner-approved 2026-11-12. Used for every evening (-PM) Short. Morning (-AM) Shorts stay on the
ranked "N facts" format in STYLE_SHEET.md. For -PM runs these rules REPLACE the N-facts-only rules
(always-N-facts topic rule, "Number 3/2/1" structure, 30-45 s length, countdown badge). Everything
else (sourcing, hook scoring, copyright, captions font, render quality, loudness, upload, Instagram,
report) still applies.

## Concept
A science thought experiment that turns a big fact into something personal for the viewer
("you", "your body", "your life"). Starts as a fun hypothetical, shows real data as proof, ends on
a surprising or emotional truth plus a question. Examples:
- "What if you could see how many heartbeats you have left?"
- "What if a number showed how many sunrises you'll see?"
- "What if you could see every atom you've ever shared with someone?"
- "What if the Sun disappeared - how long until you'd notice?"

Every number must be real and checked against a reliable source; round it, never invent it.

## Structure (45-60 s, 1080x1920, full quality)
1. HOOK (0-3 s): a simple visual rule, shown not explained. Bold caps title card. Warm, colourful scene.
2. TWIST (3-8 s): black screen, one short caps line that flips expectations. Hard cut, near silence.
3. PROOF (8-30 s): clean animated data on a dark grid - line graphs, progress bars, counters. One idea
   per screen, short caps headings, colour-coded (green = data, orange/red = warning).
4. GUT PUNCH (30-40 s): one big glowing number or word alone in the centre. Music drops to almost nothing.
5. CAUSE / MEANING (40-52 s): one simple visual explaining why, two-line caption (white line, then an
   orange emphasis line).
6. ENDING (52-60 s): a hopeful or curious closing line, then a direct question to the viewer.

## Attention rules
- Talk to "you"; small concrete numbers, not abstract big ones.
- At least 3 pattern interrupts (colourful scene <-> dark single-line screen).
- Max 6 words per on-screen text card, ALL CAPS, centred, high contrast. Something changes every 2-3 s.
- No countdown badge in this format.
- Description ends with a question ("Which number would scare you most?") plus a share trigger
  ("Send this to someone who...").
- Hashtags: #whatif #science #perspective #plainscience + 3 topic tags.

## Visual style
Flat 2D animation, simple characters, dark navy backgrounds for data screens, warm sunset tones for
story/hook scenes, soft glow on key numbers. Only free-licensed or self-drawn visuals, credited in the
description; same diagram fallback as N-facts runs if no free source is reachable.

## Music
Target mood: atmospheric, serious, reflective ambient - the Øneheart-style sound the owner likes
(think "snowfall": soft piano, slow pads, wide space).

- NEVER use Øneheart (or any other commercially released artist) tracks: they are not free-licensed
  and will get Content ID claims or strikes. Match the mood, not the artist.
- Default track: `music/whatif/sb_snowfall.mp3` - "Snowfall" by Scott Buckley, CC BY 4.0 (248 s,
  layered piano, strings, synths). Credit it EXACTLY on the Sources line / description:
  `'Snowfall' by Scott Buckley - released under CC-BY 4.0. www.scottbuckley.com.au`
- Other tracks may be added to `music/whatif/` only if they are CC0 / CC BY / YouTube Audio Library
  "no attribution required"; record each track's credit line in `music/README.md`.
- Mood arc across one track: Hook = soft piano, gentle; Twist + Proof = keep low under the voice;
  Gut punch = drop the music to near silence (duck an extra 10-15 dB or cut to a single sustained
  note); Ending = bring it back up gently, bittersweet but hopeful, 1 s fade-out.
- Same mix rules as always: ducked about 20-24 dB under the voice, voice always on top, about -14 LUFS.

## Extra gate checks (this format only)
- Every number verified, with sources in the description.
- TWIST and GUT PUNCH beats are both present and timed roughly as above - a WHAT IF Short missing
  either beat is not ready to upload.
- Length 45-60 s.
