# Music

Put downloaded royalty-free tracks here (from YouTube Studio's Audio Library,
filtered to "no attribution required"), one or a handful reused across many
Shorts. render.py should pick one, duck it ~20-24 dB under the voice, and
never use a synthesized pad/tone - see ../youtube-agent-skill/skills/yt-render/SKILL.md.

## whatif/ (18:00 "WHAT IF" Shorts only)

commercially released artists (e.g. Øneheart). Credit lines:
